# Chatbot de Apoio Emocional em Python

## Sobre o projeto

Este é um projeto pessoal desenvolvido para auxiliar pessoas de acordo com seus sentimentos momentâneos.

O chatbot funciona como um apoio simples, onde o usuário informa como está se sentindo e o sistema responde com uma mensagem de conselho ou incentivo.

O objetivo principal deste projeto é praticar lógica de programação com estruturas condicionais (`if`, `else`, `elif`) e interação com o usuário utilizando Python.

---

## Funcionalidades

* Solicita o nome do usuário
* Pergunta como a pessoa está se sentindo
* Identifica emoções como:

  * alegria
  * tristeza
  * ansiedade
  * medo
  * raiva
* Retorna uma mensagem de apoio
* Caso o usuário digite "nada", o sistema responde de forma apropriada

---

## Tecnologias utilizadas

* Python
* Lógica de Programação
* Estruturas condicionais (`if`, `elif`, `else`)
* `entrada e saida de dados`


---

## Como funciona

1. O usuário inicia o programa
2. Digita seu nome
3. O chatbot pergunta como está se sentindo
4. O sistema analisa a resposta
5. O chatbot retorna uma mensagem de apoio
