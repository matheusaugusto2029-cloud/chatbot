• Sobre o projeto: Esse é um projeto pessoal desenvolvido para auxiliar pessoas de acordo com seus sentimentos momentâneos.
Esse chatbot utiliza estruturas de decisão do tipo if,else e elif. 
•Para que serve?: ele serve para auxiliar pessoas de acordo com seus sentimentos. raiva, tristeza, ansiedade... o usuario coloca o que ele está sentindo no momento, e o chat funciona como um psicológo, dando apoio para a pessoa.
Não foram usadas nenhuma biblioteca, apenas lógica pura de programação.
•Linguagem usada: Python.
• Funcionalidades: O usuario digita seu nome, o chat pergunta como ele está se sentindo, o usuario digita alegre,medo,raiva, trsite... e o chat dá um conselho sobre o sentimento digitado pela pessoa. caso o usuario digite "nada" o chat retorna uma mensagem dizendo "já que não está sentindo nada, não tem como te auxiliar".
• Tecnologias usadas: Logicas de programação, entrada e saida de dados e estruturas condicionais (if,elif e else)
